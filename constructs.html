3.Control Structures in C (Sequentials, Conditionals and Loops)

Control structures determine the order in which instructions are executed in a C program. By default, C runs code line-by-line from top to bottom (Sequential), but programs often need to make decisions based on conditions (Conditional) or repeat a block of code multiple times (Loops). Select a topic below to explore each one:

1. Sequential Control Structure

In a sequential structure, statements execute strictly one after another in the exact order they are written—without skipping any line or repeating anything. Every basic input-process-output program follows sequential flow.

Example: Sum of Two Numbers

C Source Code (sequential_example.c)
#include <stdio.h>

int main() {
    int a, b, sum;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    sum = a + b;
    printf("Sum = %d\n", sum);

    return 0;
}
Terminal Command & Output
$ gcc sequential_example.c -o sequential_example
    $ ./sequential_example
Enter two numbers: 12 8
Sum = 20

2. Conditional Control Structure

Conditional statements (if, else if, else, and switch) let your program make decisions and run different blocks of code depending on whether a condition is True or False.

Example: Check Even or Odd

C Source Code (conditional_example.c)
#include <stdio.h>

int main(void) {
    int num;

    printf("Enter an integer: ");
    scanf("%d", &num);

    if (num % 2 == 0) {
        printf("%d is Even.\n", num);
    } else {
        printf("%d is Odd.\n", num);
    }

    return 0;
}
Terminal Command & Output
$ gcc -Wall -Wextra conditional_example.c -o conditional_example
$ ./conditional_example
Enter an integer: 17
17 is Odd.
