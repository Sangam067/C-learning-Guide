2. Variables, Data Types & Operators

What is a Variable?

A variable is a named container in computer memory (RAM) used to store data that can change while your program runs. Before using a variable in C, you must declare its data type and name.

  • Declaration: int age; (reserves memory for an integer named age).
  • Initialization: int age = 20; (creates the variable and gives it an initial value).
  • Naming Rules: Variable names can use letters, digits, and underscores (_), cannot start with a digit, and cannot have spaces or match C keywords like int or return.

Core Data Types & Format Specifiers

C is a statically typed language, meaning every variable must have a fixed data type so the compiler knows how much memory to reserve. When printing variables with printf(), you use format specifiers (like %d or %f) as placeholders.

Data Type What It Stores Typical Size Format Specifier Example
int Whole numbers 4 bytes %d int age = 20;
float Decimal numbers 4 bytes %f float price = 19.99;
double More precise decimal numbers 8 bytes %lf double salary = 50000.00;
char Single characters 1 byte %c char grade = 'A';

Qn) Try to use all the data types and print them 


#include <stdio.h>
    int main(void) {
    int age = 20;
    float height = 5.9f;
    double pi = 3.1415926535;
    char grade = 'A';

    printf("Age: %d\n", age);
    printf("Height: %.1f feet\n", height);   // .1 prints 1 decimal place
    printf("Pi: %.6lf\n", pi);              // .6 prints 6 decimal places
    printf("Grade: %c\n", grade);

    return 0;
}

Reading Input (scanf) & Arithmetic Operators

To read input from the keyboard, C uses scanf(). You must place the address-of operator (&) before the variable name so scanf() knows where in memory to store the user's input.

Watch out for Integer Division: Dividing two integers in C (such as 15 / 4) discards the decimal part and gives 3. To get a decimal result, convert at least one number to (float).

C Source Code can be found in Code Folder(calculator.c)

Qn) Write a C program to take two numbers and perform all sort of calculations like a calculator


#include <stdio.h>
        int main(void) {
    int num1, num2;

    printf("Enter two integers: ");
    scanf("%d %d", &num1, &num2);

    printf("Addition (+):       %d\n", num1 + num2);
    printf("Subtraction (-):    %d\n", num1 - num2);
    printf("Multiplication (*): %d\n", num1 * num2);
    printf("Integer Div (/):    %d\n", num1 / num2);
    printf("Remainder (%%):      %d\n", num1 % num2);
    printf("Exact Div:          %.2f\n", (float)num1 / num2);

    return 0;
}

Comparison & Logical Operators

Comparison operators (==, !=, >, <, >=, <=) and logical operators (&& for AND, || for OR, ! for NOT) evaluate conditions. In C, 1 means True and 0 means False.


C Source Code can be found in Code Folder(operators.c)
#include <stdio.h>

int main(void) {
    int marks = 82;
    int attendance = 90;

    // 1 = True, 0 = False
    printf("Passed exam (marks >= 50): %d\n", marks >= 50);
    printf("Full score (marks == 100): %d\n", marks == 100);
    printf("Eligible for honors (marks >= 80 && attendance >= 75): %d\n",
           marks >= 80 && attendance >= 75);

    return 0;
}
Terminal Output
Passed exam (marks >= 50): 1
Full score (marks == 100): 0
Eligible for honors (marks >= 80 && attendance >= 75): 1
