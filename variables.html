2. Variables, Data Types & Operators

What is a Variable?

A variable is a named container in computer memory (RAM) used to store data that can change while your program runs. Before using a variable in C, you must declare its data type and name.

  • Declaration: int age; (reserves memory for an integer named age).
  • Initialization: int age = 20; (creates the variable and gives it an initial value).
  • Naming Rules: Variable names can use letters, digits, and underscores (_), cannot start with a digit, and cannot have spaces or match C keywords like int or return.

Core Data Types & Format Specifiers

C is a statically typed language, meaning every variable must have a fixed data type so the compiler knows how much memory to reserve. When printing variables with printf(), you use format specifiers (like %d or %f) as placeholders.

Data Type What It Stores Typical Size Format Specifier Example
int Whole numbers 4 bytes %d int age = 20;
float Decimal numbers 4 bytes %f float price = 19.99;
double More precise decimal numbers 8 bytes %lf double salary = 50000.00;
char Single characters 1 byte %c char grade = 'A';

C Source Code can be found in Code Folder(datatypes.c)

Qn) Try to use all the data types and print them 


#include <stdio.h>
    int main(void) {
    int age = 20;
    float height = 5.9f;
    double pi = 3.1415926535;
    char grade = 'A';

    printf("Age: %d\n", age);
    printf("Height: %.1f feet\n", height);   // .1 prints 1 decimal place
    printf("Pi: %.6lf\n", pi);              // .6 prints 6 decimal places
    printf("Grade: %c\n", grade);

    return 0;
}
