1. Basic Theory of C Programming & Creating Your First Program

What is C?

C is a general-purpose, procedural programming language created by Dennis Ritchie in 1972. It compiles directly into fast machine code and gives you direct control over computer memory.

  • Compiled Language: A compiler (like GCC) translates your entire .c file into an executable before it runs.
  • Case-Sensitive: main and Main are treated as different names.
  • Statement Terminator: Almost every instruction in C must end with a semicolon (;).

Your First C Program

Every C program begins execution inside the main() function. The #include <stdio.h> line loads the standard input/output library so you can print text using printf().


Qn 1) Write your own C program Code to display Hello World in Output.

C Source Code can be found in Code Folder(first.c)
#include <stdio.h>
#include <conio.h>

Using Comment and Multiple Lines

Comments start with // and are ignored by the compiler. Use \n inside quotes to move text to a new line.

C source Code (lines.c)
#include <stdio.h>
      int main(void) {
    // Printing two separate lines
    printf("Welcome to C Programming!\n");
    printf("Line 2 output.\n");
    return 0;
}
Terminal Output
Welcome to C Programming!
      Line 2 output.
